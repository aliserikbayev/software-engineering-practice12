# Low-code companion

This folder documents the second implementation required by the assignment. It includes a platform-neutral declarative specification that can be recreated in Appsmith or Budibase. It is not presented as a published third-party app: no platform workspace credentials or publishing session were provided.

Start with BUILD.md. The shared test cases are in ../docs/TEST-CASES.md. Keep the inputs, fixed booking data, reason codes, and expected outcomes identical to the code implementation.
